Cytoscape-web

Cytoscape-web is a web implementation of the core functionality of Cytoscape desktop, including:

  • Network visualization
  • Import of networks and tables
  • Visual styles

Networks and Tables

Networks
e.g., PPIs or pathways

Tables
e.g., data or annotations

Visual Styles

These are the core concepts of Cytoscape that we will come back to over and over. Cytoscape knows about networks and it knows about tables (like your data). And Cytoscape allows you to define Visual Styles to map your data values to visualizations like node color, size and dozens of other properties.

Getting data into Cytoscape-web

  • Create network in Cytoscape desktop, R, python or any tools that can generate CX or CX2 files
  • Export newtork as a CX2 file or export network to NDEx
  • Import into Cytoscape-web (Data→Import→Import Network from File...) or read from NDEx (Data→Open Network(s) from NDEx...)

Sharing your data - recommended approach

Currently, the main benefit of Cytoscape-web is to share your networks with collaborators

  • Do your analysis and visualization in Cytoscape desktop
  • Export your network to NDEx
  • Get the URI of your network from NDEx (e.g. 41926c5e-2b23-11f0-a469-005056ae3c32)
  • The cytoscape-web URL will be:https://web.cytoscape.org/0/networks/41926c5e-2b23-11f0-a469-005056ae3c32
    • Note the "0" after the web.cytoscap.org -- this indicates that there is no session file yet (one will be created)

Limitations

Cytoscape-web is very new, so there are several limitations at this time that will be removed as it's development continues

  • No analysis tools (e.g. NetworkAnalyzer)
  • There are currently very few apps, so if you want to use the stringApp, ClueGO, clusterMaker2, etc., you should perform your analysis in Cytoscape desktop first
  • The layout algorithms are quite different
  • Layouts cannot be undone
  • Annotations are currently not supported
  • Local CX importer is somewhat fragile
