Agentic Integration

A Cytoscape Desktop App enables agentic applications like Claude Desktop/Code, Codex, Copilot to translate prompts into actions on the Cytoscape Desktop

  • > open network in cytoscape desktop
  • > change layout of network
  • > analyze network
  • > change color gradient of nodes from blue to red based on eccentricity
  • > generate edge colors for discrete values of interaction

Install App

  1. Have Cytoscape Desktop running
  2. Go to https://apps.cytoscape.org/ in your browser
  3. Search for mcp
  4. Choose Cytoscape MCP Server
  5. Click Install button
  6. See MCP status in bottom tray

Configure Agent

The app publishes an MCP endpoint inside Cytoscape's existing CyREST HTTP server — AI agents connect to the MCP endpoint on CyREST and invoke MCP tools which drive activity on the Cytoscape desktop display.

You can configure any agent that supports MCP with HTTP transport to connect. AgentConfiguration.md provides config instructions for Claude Desktop, Claude Code, GitHub Copilot, GitHub Copilot CLI, OpenAI Codex CLI.

Let's demonstrate connection to Claude Desktop.

  1. Go to Settings > Extensions > Advanced and enable Use Built-in Node.js for MCP. This is required for the extension to function.
  2. Utilize a pre-made MCP bundle file which only Claude Desktop supports — Download cytoscape-mcp.mcpb
  3. Drag it onto Settings > Extensions screen
  4. Go to Customize > Connectors — will see Cytoscape listed as MCP server

Agent Drives the Desktop

Will now use plain english at Agent prompt to analyze dataset file from an MS-AP experiment and generate enriched protein interaction network in Cytoscape.

Paste the content from AP MS Cytoscape Demo Prompts into your Agent prompt.

The agent will begin processing and will require you to approve intermittent tool invocations. You can specify automatic approval of cytoscape mcp tools in agent to avoid repeated tool approval requests.

Network Visualization Result

The final result on desktop will be network visualization highlighting the AP-MS experimental data (green edges), as well as additional known protein interactions via grey edges, and node color indicating the MS Jurkat Score from experiment data.
