Cytoscape Web Service Apps

REST services that extend Cytoscape Web with external analysis and automation.

What are Cytoscape Service Apps?

  • Community-built additions that extend Cytoscape Web functionality.
  • Implemented as REST services registered by URL.
  • Language-flexible: Python, Java, R, Node, Go, or anything that speaks HTTP.
  • Expose metadata so Cytoscape Web can build menus, dialogs, and parameter forms.

Service Apps vs. Cytoscape Web Apps

App typeBest forTradeoff
Web AppDeep UI integrationRequires TypeScript / web development
Service AppBackend analysis, layouts, conversions, automationMore limited Cytoscape Web API access

Basic Service App Contract

GET    /              metadata: name, menu item, params, input definition
GET    /status        service health
POST   /              submit task, returns task id
GET    /<taskID>/status  task progress
GET    /<taskID>         final task result
DELETE /<taskID>         cancel/delete task

Why use Service Apps?

  • Reuse existing scientific code without rewriting it in the browser.
  • Run heavier jobs outside the Cytoscape Web client.
  • Package analysis as a simple HTTP service.
  • Expose new workflows through the Cytoscape Web Apps menu.

Good Fit Use Cases

  • Network enrichment services
  • Custom layouts
  • Network or table updates
  • External database lookups
  • Model-based predictions or scoring pipelines

Design Pattern

  1. Cytoscape Web sends selected network data and parameters.
  2. The service starts a task and returns an id.
  3. Cytoscape Web polls task status.
  4. The service returns a result action Cytoscape Web can apply.

How to Add a Service App to Cytoscape Web

  1. Open Cytoscape Web.
  2. Go to Apps → Manage Apps.
  3. Paste the Service App URL into External Service URL.
  4. Click Add.
  5. Launch it from the Apps menu.

Example Service App URL

https://cd.ndexbio.org/cy/cytocontainer/v1/updatetablesexample

After registration, the app appears under the Apps menu, for example: Example Service App → Update tables example.

Important Workspace Note

Active Apps and Service Apps can be cleared when using Data → Clear Local Database.

To preserve enabled apps, save a workspace snapshot to NDEx with Data → Save Workspace As….

Create a Simple Service App with Python + Flask

Goal: a tiny service that registers in Cytoscape Web, accepts a task, and returns a completed result.

Install

python -m venv .venv
source .venv/bin/activate
pip install flask flask-cors

Minimal Flask Skeleton

from flask import Flask, request, jsonify
from flask_cors import CORS
from uuid import uuid4

app = Flask(__name__)
CORS(app)

tasks = {}

Metadata Endpoint

@app.get("/")
def metadata():
    return jsonify({
        "name": "Hello Service App",
        "description": "A minimal Cytoscape Web Service App",
        "author": "Your Name",
        "version": "1.0.0",
        "showDescriptionInDialog": True,
        "cyWebActions": ["updateTables"],
        "cyWebMenuItem": {
            "rootMenu": "Apps",
            "path": ["Example Service App"],
            "name": "Hello Service App"
        },
        "serviceInputDefinition": {
            "type": "network",
			"scope": "all"
        },
        "parameters": [
            {
                "displayName": "Greeting",
                "type": "string",
                "defaultValue": "Hello from Flask"
            }
        ]
    })

Health Endpoint

@app.get("/status")
def status():
    return jsonify({
        "status": "ok",
        "version": "1.0.0",
        "numberOfRunningTasks": 0
    })

Submit a Task

@app.post("/")
def submit_task():
    payload = request.get_json(force=True)
    task_id = str(uuid4())

    greeting = payload.get("parameters", {}).get("Greeting", "Hello")

    tasks[task_id] = {
        "id": task_id,
        "status": "complete",
        "progress": 100,
        "message": "Task complete",
        "result": {
            "data": {
                "greeting": greeting
            }
        }
    }

    return jsonify({"id": task_id}), 202

Task Status + Result

@app.get("/<task_id>/status")
def task_status(task_id):
    task = tasks.get(task_id)
    if task is None:
        return jsonify({"message": "Task not found"}), 404
    return jsonify({
        "status": task["status"],
        "progress": task["progress"],
        "message": task["message"],
        "result": None
    })

@app.get("/<task_id>")
def task_result(task_id):
    task = tasks.get(task_id)
    if task is None:
        return jsonify({"message": "Task not found"}), 404
    return jsonify(task)

Delete / Cancel Task

@app.delete("/<task_id>")
def delete_task(task_id):
    if task_id not in tasks:
        return "", 404
    del tasks[task_id]
    return "", 204

Run Locally

if __name__ == "__main__":
    app.run(host="0.0.0.0", port=5000, debug=True)
python app.py

Try It

curl http://localhost:5000/status
curl http://localhost:5000/
curl -X POST http://localhost:5000/ \
  -H 'Content-Type: application/json' \
  -d '{"parameters":{"Greeting":"Hi Cytoscape Web"},"data":{}}'

Developer Checklist

  • Implement required endpoints.
  • Return valid metadata from GET /.
  • Support CORS for Cytoscape Web.
  • Use stable task ids.
  • Return progress, status, message, and result consistently.
  • Keep result actions aligned with Cytoscape Web’s expected result schema.
