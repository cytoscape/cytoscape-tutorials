What are Service Apps?

  • A way for you to extend Cytoscape Web functionality.
  • Can be written in any language that supports REST services.
  • Can be run by you locally or served from a remote server.
  • Ability to call from Cytoscape Desktop coming soon.

Service Apps vs. Web vs. Desktop Apps

App typeBest forTradeoff
Desktop AppDeep UI integrationDesktop only, requires Java development
Web AppDeep UI integrationWeb only, requires TypeScript / web development
Service AppLanguage-agnostic No/Limited API access, requires hosting

How to Add a Service App to Cytoscape Web

  1. Open Cytoscape Web.
  2. Go to Apps → Manage Apps...
  3. Click SERVICE APPS tab.
  4. Paste the Service App URL into External Service URL.
  5. Click Add.
  6. Launch it from the Apps menu.

Example Service App URL

https://cd.ndexbio.org/cy/cytocontainer/v1/updatetablesexample

After registration, the app appears under the Apps menu

For example: Example Service App → Update tables example.

This App requires a network. You can get some networks by clicking Data → Open Sample Networks.

How Service Apps Work

Service Apps are REST services that implement a specific contract.

Visit Cytoscape Web App Developers Guide for more details.

Endpoints

Highlevel view of Service App REST endpoints

GET    /              metadata: name, menu item, params, input definition
GET    /status        service health
POST   /              submit task, returns task id
GET    /<taskID>/status  task progress
GET    /<taskID>         final task result
DELETE /<taskID>         cancel/delete task

Metadata

Provides information about the service. Called by Cytoscape Web when registering the Service App.

GET    /              metadata: name, menu item, params, input definition
Response 
{
    "serviceInputDefinition": Object (SelectionMethod), # Data wanted
    "cyWebActions": [string], # Data generated
    "cyWebMenuItem": Object (RootMenu), # Menu location
    "name": string, 
    "description": string,
    "showDescriptionInDialog": boolean,
    "author": string,
    "citation": string,
    "version": string,
    "parameters": [ # UI parameters
      Object (Parameter)
    ]
}

Status

Provides information about the health of the service. In future will be called by Cytoscape Web and AppStore to monitor service health.

GET    /status        service health
Response Example 
{
  "status": "ok",
  "version": "1.0.0",
  "numberOfRunningTasks": 0
}

Submit task

Submits a task to the service. Called by Cytoscape Web when a user clicks Submit on Service App dialog.

POST   /              submit task, returns task id
Request Example 
{
	"parameters":{"someparam": "somevalue"},
	"data":[{"CXVersion": "2.0" ... }]
}
Response Example 
{"id":"9a363a0b-bdc2-40a7-91ba-19657bdac156"}

Task status

Provides information status of a task excluding the final result. Cytoscape Web polls this endpoint waiting for task completion.

GET    /<taskID>/status  task progress
Response Example 
{
	"id":"9a363a0b-bdc2-40a7-91ba-19657bdac156",
	"message":null,
	"progress":100,
	"startTime":1780005354862,
	"status":"complete",
	"wallTime":10
}

Task final result

Provides task final result. Called by Cytoscape Web after task is complete.

GET    /<taskID>  task final result
Response Example 
{
	"id":"9a363a0b-bdc2-40a7-91ba-19657bdac156",
	"result": [ {"action": "updateNetwork",
	             "data": [{"CXVersion": "2.0" ... }]} ],
	"message":null,
	"progress":100,
	"startTime":1780005354862,
	"status":"complete",
	"wallTime":10
}

Delete task

Deletes a task from the service, called by Cytoscape Web after obtaining result.

DELETE /<taskID>  delete task
Successful deletion has no needed response

Hands-on Exercise

Simple Service App with Python + Flask

Goal: a tiny service that accepts a network, adds a few nodes and returns an updated network.

Developer Checklist

  • Implement required endpoints.
  • Return valid metadata from GET /.
  • Support CORS for Cytoscape Web.
  • Use stable task ids.
  • Return progress, status, message, and result consistently.
  • Keep result actions aligned with Cytoscape Web’s expected result schema.

Visit the Specification for Service App in Cytoscape Web.

Set up

  1. Click here to download addnodes.py example
  2. Open a terminal
  3. Install dependencies:
    4. 
pip install flask flask-cors ndex2

Run Locally

python addnodes.py
Try it locally (requires curl) 
curl http://localhost:8080/addnodes/status
curl http://localhost:8080/addnodes
curl -X POST http://localhost:8080/addnodes \
  -H 'Content-Type: application/json' \
  -d '{"parameters":{},"data":[{"CXVersion": "2.0", "hasFragments": false}, {"metaData": [{"elementCount": 1, "name": "attributeDeclarations"}, {"elementCount": 1, "name": "networkAttributes"}, {"elementCount": 2, "name": "nodes"}, {"elementCount": 1, "name": "edges"}]}, {"attributeDeclarations": [{"nodes": {"name": {"d": "string"}, "altname": {"d": "string"}, "represents": {"d": "string"}}, "edges": {"interaction": {"d": "string"}, "weight": {"d": "double"}}, "networkAttributes": {"name": {"d": "string"}}}]}, {"networkAttributes": [{"name": "test network"}]}, {"nodes": [{"id": 0, "x": 10, "y": 0, "v": {"name": "foo", "altname": "alternate name for foo", "represents": "representing foo"}}, {"id": 1, "x": 10, "y": 10, "v": {"name": "bar", "altname": "alternate name for bar", "represents": "representing bar"}}]}, {"edges": [{"id": 0, "s": 0, "t": 1, "v": {"interaction": "interacts", "weight": 0.5}}]}, {"status": [{"error": "", "success": true}]}]}'

If curl is not available, paste the first two URLs into a browser.

Try it in Cytoscape Web

  1. Open Cytoscape Web. https://web.cytoscape.org
  2. Go to Apps → Manage Apps... and click SERVICE APPS tab.
  3. Paste http://localhost:8080/addnodes into External Service URL text field and clickAdd.
  4. Get some networks by clicking Data → Open Sample Networks.
  5. Launch it by invoking Apps → Example Service App → Python-Flask Simple Service-App.

After invocation, additional nodes should appear in the network.
